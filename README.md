HRFNet (Hyperspectral-RGB Fusion Network) is a deep learning model for rapid, non-destructive quality classification of agricultural products. The model fuses hyperspectral and RGB image information to combine composition-related spectral responses with appearance-related visual features.
Using tobacco leaves as a representative agricultural product, 94,500 paired hyperspectral-RGB image patches were constructed from 378 samples. PCA was applied to reduce the original 480-band hyperspectral input, with 30 principal components selected for the final model. HRFNet achieved 95.97% overall accuracy, 95.53% average accuracy, and a Cohen’s kappa coefficient of 93.70%, outperforming hyperspectral-only and RGB-only baselines.
